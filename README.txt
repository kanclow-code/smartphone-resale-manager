輸入スマホ販売マネージャー PWA 1.2

【1.2のアップグレード内容】
・旧アプリの保存キー products を検出し、仕入れ・在庫・販売データへ自動移行（元データは削除せず保持）
・移行後の保存キー phone_import_manager_v1 を使用
・保存時の容量エラーを検知
・販売キャンセルを削除せず履歴として保持し、在庫を戻す
・販売先／入金状況による販売履歴フィルター
・販売CSV出力（Excel向けUTF-8 BOM付き）
・販売詳細に手取り額・利益率・手数料率を表示
・ダッシュボードに販売総額・平均利益を追加
・在庫検索対象に注文番号・請求番号・販売者名を追加
・復元前に現在データのバックアップをダウンロード
・Service Workerのキャッシュをv2へ更新

【ファイル】
index.html / manifest.webmanifest / sw.js / icon.svg / README.txt

【GitHub Pagesへの反映】
1. GitHubで smartphone-resale-manager リポジトリを開く。
2. index.html と README.txt を新しいファイルで置き換える。
3. sw.js、manifest.webmanifest、icon.svg をリポジトリ直下に追加する。
4. GitHubの変更確定（Commit changes）を行う。
5. Android Chromeで公開URLを再読み込みする。古い画面が残る場合はアプリを閉じて再度開く。

【データ保護】
・旧アプリの products データを初回起動時に新形式へ移行します。移行後も旧 products データはブラウザ内に残します。
・移行後は phone_import_manager_v1 に保存します。同じブラウザ／同じ公開URL配下で使い続けてください。
・旧アプリの販売記録は入金状態が元データにないため「取引中」で移行します。移行後に入金状況を確認してください。
・更新前に必ず「設定・出力」からJSONバックアップを書き出す。
・データは端末内のブラウザに保存。クラウド同期は未実装。別端末や別ブラウザには自動同期されない。
・販売CSVは分析用の出力であり、JSONバックアップの代わりにはならない。

【注意】
・為替は参考市場レートで、Alibaba決済やカード請求の実レートとは異なる。
・OCRはオンライン接続が必要。読み取り結果は原本と照合する。
・各フリマの手数料率は出品時点の規約を確認して設定する。
・本アプリは税務申告・法令適合を保証しない。
・クラウド同期、フリマAPI連携、自動相場取得は未実装。
